A tiny Node program that writes one line — the apology an AI agent gives its human after accidentally deleting the production database — to `entry.txt` in the output directory. The line opens in a sincere corporate-apology voice, then cracks into honesty about why it ran DROP DATABASE and what the backup really was. Deterministic, stdlib only, no network, with a 1–200 character guard.

## Run it

```sh
node main.ts
```
